Course registry
OpenGolfAPI (16,800+ U.S. courses, free, ODbL) seeds identity, tees, pars, yardage. golfapi.io / iGolf as commercial upgrades.
STATUS · AVAILABLE
Hole geometry
OpenStreetMap leisure=golf tags via Overpass API — tee, fairway, bunker, green polygons where the community has mapped them. Coverage varies; gate the Terrain axis on it.
STATUS · PARTIAL COVERAGE
Elevation
USGS 3DEP point-query API sampled along each hole centerline — free, 1-meter DEM across most of the U.S. This replaces every demo profile above.
STATUS · AVAILABLE
Ratings & slope
USGA course rating database + state golf association pages (like GAP) as verification layer. Two sources disagree → field flagged, not averaged.
